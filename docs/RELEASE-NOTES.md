Usage Atlas 0.3.4 — AGY 사용률 평준화

- 작은 사용률 하락으로 잘게 끊기던 AGY 사용률 차트를 기본 5분 시간 가중 평균으로 정리합니다. 1%p 이하 하락의 반복 마커도 줄입니다.
- Antigravity Smoothing Minutes 설정으로 0~60분을 지정하며 0은 원래 표시입니다. 페이지·미리보기에 공통 적용됩니다.
- 현재 값과 실제 초기화 경계는 유지합니다. 원본 기록·변화량·누적·예측 계산은 변경하지 않습니다.

Windows·WSL용 VSIX와 SHA256입니다. 기존 설정과 기록을 보존하며 GitHub Releases 배포를 유지합니다.
