Usage Atlas 0.2.24 — 탭 전환 후 시간 범위 유지

- 다른 탭을 보고 돌아와도 선택한 확대·이동 범위를 유지합니다.
- 숨김 중 새 데이터와 설정 갱신, 기존 탭의 Usage 명령 재실행에서도 선택 범위를 보존합니다.
- Webview는 기존처럼 숨김 상태에서 해제하며, 상태 저장 API로 시간 범위를 복원합니다.
- 새 탭의 기본 기간과 Home·범위 조절기 더블클릭·기간 설정 변경에 따른 초기화는 유지합니다.

Windows·WSL용 VSIX와 SHA256을 첨부합니다. 소스·라이선스는 저장소에서 확인할 수 있으며 Marketplace 등록과 자동 배포는 활성화하지 않습니다.
