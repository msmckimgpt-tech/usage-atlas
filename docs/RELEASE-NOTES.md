Usage Atlas 0.3.35 — 모델 카드 Ctrl+클릭 단독 표시

- 모델 카드를 Ctrl+클릭하면 그 모델만 표시하고, 다시 Ctrl+클릭하면 전체를 복원합니다.

Usage Atlas 0.3.34 — 예측 시각별 예측 기록

- 예측 기록을 고른 시각(지금 기준 1주일 전~최신)에 기록돼 있던 예측 한 줄로 볼 수 있습니다.
- 두 저장된 예측 사이는 베지어 곡선으로 이어 붙이고, 시각 하나를 고정해 비교할 수 있습니다.

Usage Atlas 0.3.33 — 모델 카드 하단 정리

- 모델 카드 하단의 빈 줄을 없애고 상태·시각과 크레딧 문구를 한 줄에 합쳤습니다.

---

Usage Atlas 0.3.32 — 모델 카드 사용량 막대

- 모델 카드의 5시간·주간 줄에 사용률 막대를 넣었습니다(미리보기 표와 같은 모양).
- 요금제를 모델명 오른쪽에 작게 표시하고 하단 공간을 줄였습니다.

---

Usage Atlas 0.3.30 — 차트 포커스 테두리 수정

- 상세 창을 닫은 뒤 차트에 흰색 네모 테두리가 남던 문제를 고쳤습니다.
- 차트 빈 곳을 마우스로 클릭할 때 파란 테두리가 생기던 문제를 고쳤습니다. 키보드 포커스에서는 그대로 보입니다.

Usage Atlas 0.3.29 — 미리보기 범례를 모델별 표의 색 표식으로 통합

- 그래프 위 모델 범례를 없애고 표의 모델 이름 앞에 색 표식을 넣었습니다.
- 미리보기 높이가 16px 줄었습니다.

Windows·WSL용 VSIX와 SHA256입니다.
