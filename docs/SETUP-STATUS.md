0.3.7은 페이지 차트에서 커서에 가장 가까운 논리 그래프를 강조합니다. 동일 모델의 5시간·주간·추가 크레딧을 구분하고 대응하는 보간선·예측선·마커를 연결합니다. 선택한 선은 1.8px/불투명이며 다른 선과 영역은 원래 투명도의 18%가 됩니다. 빈 공간·차트 이탈·기존 키보드 Escape 경로에서 복원하고 자동 갱신 후에도 정지한 커서의 화면 좌표로 다시 판정합니다. 상단 모델 강조와 기존 상세 툴팁은 유지합니다.

기존 거리 판정을 공유하고 강조 대상이 같으면 DOM 탐색/스타일 쓰기를 건너뜁니다. hover 전용 타이머나 차트 전체 재렌더를 추가하지 않았습니다. UI 검수는 실제 pointer 이벤트, 계산된 선 굵기/투명도, 같은 모델 내 주기 구분, 정지한 커서/데이터 재수신, 동일 선 내 이동 시 노드·경로 보존과 반복 스타일 쓰기 0회, 빈 공간/이탈 복원 및 보간·예측·AGY를 확인했습니다. 기존 휠·중간 버튼 이동·우클릭 확대·탭 범위·반응형·크레딧 회귀 검수도 통과했습니다.

Windows 418 PASS/1 SKIP, WSL 418 PASS/1 SKIP(각 419조건)입니다. WSL은 순차 실행했습니다. 필수 17단계 배포 게이트와 실제 VS Code/CSP 검수가 통과했습니다. 단위 집계나 원본 저장 형식은 변경하지 않았으며 장기 크레딧/아카이브 회귀 검수를 유지합니다. 실제 VS Code 검수는 제공자 조회 0건이고 탭 3회 전환·숨김 중 갱신·재열기 기본 범위도 확인했습니다.

Windows 2개 프로필과 WSL 2개 사용자 설치를 0.3.7로 갱신했습니다. 세 위치의 파일 49개씩과 설정 파일 4개의 해시 보존을 확인했습니다. 원본 DB·기록·로그인을 덮어쓰거나 사용자 창을 강제로 재시작하지 않았습니다. 실행 중인 창은 다시 불러와야 새 코드가 활성화됩니다. npm 의존성·수집 주기는 0.3.6과 같습니다.

실제 기록·DB/WAL/SHM·로그·설정·인증은 공개 소스/VSIX에 포함하지 않습니다. 기존 소스·VSIX 공개 범위와 라이선스 고지를 유지하며 원격 CI·Marketplace 게시·추가 인증은 활성화하지 않았습니다.
