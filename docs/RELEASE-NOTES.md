Usage Atlas 0.3.22 — Antigravity 요금제별 기본 배율 자동 적용

- Antigravity 요금제가 바뀌었을 때 기본 요금제(Pro) 대비 배율을 자동으로 적용합니다. `g1-pro-tier`는 1배, `g1-ultra-lite-tier`(x5 Ultra)는 5배를 기본값으로 쓰므로, 배율을 직접 입력하지 않아도 요금제 전환 전후의 사용량을 같은 기준으로 비교할 수 있습니다.
- 직접 입력한 배율이 있으면 그 값이 우선합니다. 그 밖의 요금제 ID는 이전처럼 보정하지 않습니다.
- 수집·저장 형식과 상세 분석 화면은 0.3.21과 같습니다.

Windows·WSL용 VSIX와 SHA256입니다.
