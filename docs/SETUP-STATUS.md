Windows 407 PASS/1 SKIP, WSL 407 PASS/1 SKIP(총 408조건)입니다. WSL은 순차 실행했습니다. 필수 17단계 배포 게이트와 실제 VS Code 검수가 통과했습니다. 새 단위 검수는 시간 가중 평균·비파괴성·초기화·계정 복귀·요금제/배율·큰 하락·결측·압축 후 경계·OFF 복구·미리보기 일치를 확인합니다. 호스트와 UI는 설정 즉시 반영·선의 좌표·≈ 툴팁·최신 값·초기화 마커·범위/배치 보존을 확인합니다. 화면 검수는 합성이며 제공자 조회를 추가하지 않습니다. 과거 날짜가 고정된 예측 UI 표본도 실행 시각 기준으로 바꾸고 기존 검증을 유지했습니다.
