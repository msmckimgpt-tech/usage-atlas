Usage Atlas 0.3.21 — 상세 분석 화면 디자인 정리

- 그래프 선을 눌러 여는 상세 분석 화면의 디자인을 다시 정리했습니다. 제목에 메인 그래프와 같은 제공자 표식·색을 붙여 'Codex 5시간 사용량'처럼 어떤 선을 열었는지 바로 보이게 했고, 탭은 밑줄형으로 바꿨습니다.
- 요약 지표를 괘선으로 나뉜 셀로 바꾸고 가격 확인 소계(USD)를 가장 크게 보여 줍니다. 새 입력·캐시 입력·출력 토큰의 비중을 한 줄 막대로 함께 표시합니다(캐시가 입력보다 큰 기록에서는 그리지 않습니다).
- 표의 숫자 열을 오른쪽 정렬하고, 값이 없는 칸(`-`)은 흐리게, 정렬 중인 열은 화살표로 표시합니다. 모델명·시각이 글자 중간에서 줄바꿈되던 문제도 고쳤습니다.
- 상세 화면의 시각을 `2026-11-21 03:46:34` 형식으로 통일하고 캐시 비율은 소수 첫째 자리까지 표시합니다.
- 수집·예측·저장 형식과 차트 동작은 0.3.20과 같습니다.

Windows·WSL용 VSIX와 SHA256입니다.
