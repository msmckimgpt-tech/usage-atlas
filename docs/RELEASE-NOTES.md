Usage Atlas 0.3.23 — 친화적 상세 분석 레이아웃·프로젝트별 히트맵·탭 전환 시 상세/대화 보존

- 그래프 클릭 상세 분석 화면을 상단 인라인 필터, 핵심 요약·토큰 구성 + 프로젝트별 GitHub Contribution 스타일 활동 히트맵 2열 배치, 고정 헤더 부분 스크롤 표 및 보기 전환으로 재구성해 세로 스크롤 압박을 해소했습니다.
- 프로젝트별·시간 구간별 사용량(환산액·호출·토큰)을 5단계 명도 히트맵으로 한눈에 비교하고 클릭 한 번으로 프로젝트를 필터링할 수 있습니다.
- VS Code에서 다른 편집기 탭에 다녀와도 열려 있던 상세 화면과 선택한 탭·필터가 그대로 유지됩니다.
- '대화 보기'로 연 세션 대화가 모달 내 탭·필터 이동 및 VS Code 탭 전환 후에도 손실되지 않고 보존됩니다(대화 본문은 저장하지 않고 로컬 기록에서 온디맨드로 복원).

Windows·WSL용 VSIX와 SHA256입니다.
