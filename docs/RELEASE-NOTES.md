Usage Atlas 0.3.15 — 차트 hover·줌 화면 반응 속도 개선

- 차트 hover 및 줌/리드로우 반응 속도를 크게 개선했습니다(합성 50,000건 기준 초기 렌더 -31%, hover p50 -59%, 줌아웃 p95 -82%).

- 툴팁 내용 캐싱 및 `transform: translate3d` 이동, `draw()` 중 직접 강조 색인, 무할당 축 범위 계산과 경계 중복 리드로우 생략을 적용했습니다.
- 수집·예측·저장 형식은 0.3.14와 같습니다.
