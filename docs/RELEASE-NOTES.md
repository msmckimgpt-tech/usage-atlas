Usage Atlas 0.3.13 — 대량 기록 성능 개선과 경로 비노출

- 화면과 웹뷰 데이터에서 로컬 저장 경로를 제거했습니다(0.3.12). 사용자 이름이 포함된 경로가 더 이상 표시되지 않습니다.
- 기록이 많을 때 그래프 부하를 줄였습니다. 합성 50,000건 기준 마우스 이동은 중앙값 약 2ms, 확대 상태의 다시 그리기는 약 3~5ms입니다. 전체 기간을 한 화면에 보는 가장 넓은 보기는 아직 약 25~30ms입니다.
- 보이는 시간 범위만 잘라 픽셀 열마다 첫·마지막·최소·최대 점만 그리며, 계산 결과는 확대·이동 중 재사용합니다.
- 수집·예측·저장 형식은 0.3.11과 같습니다.

Windows·WSL용 VSIX와 SHA256입니다.
