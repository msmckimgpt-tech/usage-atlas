Usage Atlas 0.3.25 — 모델별 예상 사용량 기록과 실제 사용량 비교 토글

- 0.3.23·0.3.24에서 설치 파일이 만들어지지 않던 배포 검사 문제를 고쳤습니다. 이 버전에 0.3.24의 기능이 포함됩니다.

- 모델별 예상 사용량(5시간·주간)을 주기적으로 기록하고, 그래프 우측 하단 **예측 기록** 버튼으로 이미 지나간 구간의 과거 예상선을 실제 사용량 위에 겹쳐 볼 수 있습니다.
- 실제 소진이 예상과 같은 모양으로 진행되는지 비교하는 기록용 기능이며, 다른 컨트롤과 그래프 배치는 바뀌지 않습니다.
- 기록은 로컬 확장 저장 폴더에만 시각·사용률 숫자로 남고 5시간 창 7일, 주간 창 21일 보관합니다.

Windows·WSL용 VSIX와 SHA256입니다.
