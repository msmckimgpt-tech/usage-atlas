Usage Atlas 0.3.18 — Antigravity 주간 예측선 복원과 그래프 끊김 수정

- Antigravity 모델의 주간(및 5시간) 사용량 예측선이 1%p 미만의 사용률 흔들림 때문에 표시되지 않던 문제를 수정했습니다. 예상선은 실제 마지막 관측값에서 시작합니다.
- 유휴 수집 간격(최대 60분)에서도 Antigravity 선이 30분마다 끊기지 않도록 설정한 최대 수집 간격을 따릅니다.
- 초기화 시각 직후 수집된 이전 주기의 마지막 값이 선에서 떨어져 보이지 않게 했습니다.
- 수집·저장 형식은 0.3.17과 같습니다. 학습된 예측 보정은 한 번 다시 계산됩니다.

Windows·WSL용 VSIX와 SHA256입니다.
